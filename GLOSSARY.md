# Glossary

Begrippen van deze app. Gebruik deze woorden in UI-tekst, code-commentaar, docs en gesprekken; geen synoniemen. De kolom "In de code" geeft de Engelse naam in code en database.

| Begrip    | Betekenis                                   | In de code                             |
| --------- | ------------------------------------------- | -------------------------------------- |
| Gebruiker | Iemand die kan inloggen                     | Prisma-model `User` (tabel `users`), rol `user` |
| Beheerder | Gebruiker die de app beheert                | Rol `admin` in `User.roles`            |
